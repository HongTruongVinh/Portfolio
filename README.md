### Description

TechStore is a full-stack e-commerce web application for selling technology products.

Customers can:

* Browse products
* Search and filter products by category and price
* Manage their accounts
* Manage shopping carts
* Apply vouchers and promotional discounts
* Place orders
* Make online payments through banking applications
* Track order status
* Get product consultation through an AI-powered chatbot

The system also provides an **Admin Dashboard** for managing:

* Products
* Categories
* Brands
* Vouchers
* Users
* Orders
* Other system data
